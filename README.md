# Muddana Ahalya - Professional Portfolio

A modern, responsive, and cyber-glassmorphic portfolio website showcasing the technical achievements, projects, skills, education, and credentials of **Muddana Ahalya** (B.Tech in Information Technology).

## 🌟 Key Features

- **Fluid Cyber-Glassmorphism Aesthetic**: Rich dark theme with custom dynamic mouse-following ambient glowing blob, backdrop blurs, and neon accents.
- **Dynamic Typewriter Subtitle**: Animated multi-phrase rotation highlighting key engineering roles.
- **Organic Profile Avatar**: Morphing organic border radius with tech badge indicators and tilt hover animations.
- **Featured Projects Showcase with UI Previews**:
  - **Smart Soil Nutrient and Moisture Monitoring System** (IoT, RS485 Modbus, Arduino, Node.js, Express, Python Scikit-Learn Decision Trees, Chart.js) with real-time UI preview and an interactive **Live Telemetry & Crop Recommender Simulator**.
  - **VecTorium: Hybrid Deep Learning Ensemble for Brain Tumor Classification** (EfficientNetB3, ResNet50, VGG16, TensorFlow/Keras, OpenCV, 96.73% validation accuracy) with Grad-CAM heatmap visualization preview and an interactive **Ensemble MRI Diagnostic Classifier Simulator**.
  - Category filters (`All`, `AI & Deep Learning`, `IoT & Full Stack`) and architecture deep-dive popups.
- **Interactive Project Simulators**:
  - Drag real-time NPK & Moisture sliders to watch the Decision Tree predict crop suitability in real-time.
  - Select 4 clinical MRI scan cases to trigger VecTorium CNN feature concatenation and see confidence percentages.
- **Technical Skills Matrix**: Visual proficiency progress bars and grouped technology chips across programming, AI/ML, cloud, and hardware.
- **Chronological Timelines**:
  - **Work Experience**: AI-ML Virtual Intern (end-to-end ML workflows, AWS SageMaker, Bedrock, Forecast).
  - **Education**: B.Tech in IT (QIS College - 8.3 CGPA), Intermediate (85.7%), SSC (100% distinction).
- **Industry Certifications**: Spring & Angular (Infosys), Python Full Stack (EduSkills), AWS Academy Cloud Foundations (Amazon), Python Programming (CodeTantra).
- **Direct Resume Download**: Direct one-click download linked to `Muddana_Ahalya_updated.pdf`.
- **Interactive Contact Section**: Direct contact cards with one-click clipboard copying, simulated messaging with validation, and social handles.
- **Full Responsiveness**: Optimized for desktops, tablets, and mobile devices with a slide-out glass drawer navigation.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup with meta-tags and SEO optimization.
- **CSS3 (Vanilla)**: Custom CSS variables, glassmorphic card tokens, keyframe animations, and flex/grid responsive layouts.
- **JavaScript (Vanilla)**: Modern ES6+ interaction engine, Intersection Observer API, smooth scrolling, physics-based mouse tracking, and toast notifications.
- **Icons & Fonts**: Google Fonts (*Outfit*, *Inter*, *Fira Code*) & Font Awesome 6.

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or serve it locally using Python:

```bash
# Using Python built-in HTTP server:
python -m http.server 3000
```

Then visit:
```
http://localhost:3000
```
